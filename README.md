# College-Timetable-Generator

A web-based application that generates college timetables using Python, Flask, and a constraint-based scheduling algorithm. It provides a browser-based interface for entering scheduling inputs, generating timetables, and viewing the results.

## Features

- Timetable generation using scheduling constraints.
- Input validation and handling of invalid scheduling requests.
- Browser-based user interface built with HTML, CSS, and JavaScript.
- Automated testing using `pytest`.
- Continuous Integration checks using GitHub Actions.

## Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Testing:** pytest
- **CI:** GitHub Actions

## Getting Started

### Prerequisites

- Python 3.x
- pip

### Installation

Clone the repository:

```bash
git clone https://github.com/harshithabt/college-timetable-generator.git
cd college-timetable-generator
```

Install dependencies:

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

Open the local URL displayed in the terminal in your browser.

## Run Tests

```bash
python -m pytest -v
```
